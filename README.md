# Disease Recognition System

A machine learning-based system that recognizes diseases from uploaded images.

## Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Streamlit

## Diseases Recognized

- Acne
- Eczema
- Psoriasis

## How It Works

1. User uploads an image.
2. The image is processed.
3. The trained deep learning model analyzes the image.
4. The system predicts the disease.
